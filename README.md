# VocaType — تایپ صوتی Chrome

افزونهٔ Manifest V3 برای دیکتهٔ فارسی در فیلدهای متنی وب، با فرمان‌های صوتی، درج متن در محل مکان‌نما، تاریخچهٔ اختیاری و یکسان‌سازی واژه‌های فنی. موتور تشخیص، فقط `SpeechRecognition` / `webkitSpeechRecognition` داخلی Chrome است؛ این پروژه مستقیماً به سرویس STT شخص ثالثی وصل نمی‌شود و به API key نیاز ندارد.

## نکتهٔ مهم: زبان و حریم خصوصی

- Web Speech API یک مقدار زبان برای هر نشست تشخیص می‌گیرد. گزینهٔ خودکار بر پایهٔ زبان مرورگر یکی از زبان‌های پشتیبانی‌شدهٔ افزونه را انتخاب می‌کند؛ «خودکار» به معنی شناسایی مطمئن جابه‌جایی زبان در میانهٔ جمله نیست.
- تشخیص ترکیبی فارسی، English و عربی تضمین نمی‌شود. برای گفتار غالباً فارسی «فارسی» و برای گفتار غالباً انگلیسی «English» را انتخاب کنید. واژگان یا قواعد متن، دقت آکوستیکی تشخیص یا code-switching را بهبود نمی‌دهند.
- خود افزونه فایل صوتی خام را ضبط یا ذخیره نمی‌کند؛ با این حال Chrome ممکن است صدا را برای تشخیص به سرویس گفتار Google بفرستد. پردازش کاملاً محلی تضمین نیست و رفتار می‌تواند با نسخهٔ Chrome، زبان و تنظیمات مرورگر تفاوت داشته باشد. اگر این موضوع برای دادهٔ شما قابل‌قبول نیست، دیکته را شروع نکنید.
- متن تاریخچه به‌صورت پیش‌فرض خاموش است. واژگان سفارشی فقط پس از دریافت transcript و به‌صورت محلی برای استانداردسازی متن اعمال می‌شوند.

## نصب

1. فایل ZIP را دانلود و از حالت فشرده خارج کنید.
2. در Chrome به `chrome://extensions` بروید و **Developer mode** را روشن کنید.
3. **Load unpacked** را بزنید و پوشهٔ `vocatyp-extension` را از فایل استخراج‌شده انتخاب کنید.
4. صفحهٔ مقصد را باز یا تازه‌سازی کنید، در یک فیلد متنی کلیک کنید و از Popup یا میانبر `Ctrl+Shift+2` تایپ صوتی را شروع کنید.

دانلود مستقیم آرشیو این شاخه: [VocaType-Chrome-Extension.zip](https://raw.githubusercontent.com/javadisaloo1111/Single-page-of-the-site/arena/01a106d6-single-page-of-the-site/VocaType-Chrome-Extension.zip)

## استفاده

- زبان گفتار، نمایش متن موقت، حالت پیوسته و تلاش مجدد را از Options تنظیم کنید.
- انتخاب زبان در نشست به `recognition.lang` مرورگر داده می‌شود. اگر حالت خودکار زبان دلخواهتان را انتخاب نمی‌کند، زبان را صریحاً تعیین کنید.
- واژگان فنی داخلی و سفارشی شکل واژه‌های تشخیص‌داده‌شده را استاندارد می‌کنند؛ این فهرست به موتور گفتار ارسال نمی‌شود و واژهٔ تازه را به مدل آکوستیکی نمی‌آموزد.
- فرمان‌هایی مثل «خط جدید»، «پاراگراف جدید»، «نقطه» و «پاک کن» فقط وقتی به‌صورت یک بخش نهایی مستقل تشخیص داده شوند اجرا می‌شوند.
- Copy/Paste صوتی نیازمند مجوز اختیاری Clipboard است و فقط پس از اقدام کاربر درخواست می‌شود.
- برخی فیلدهای خاص، صفحات داخلی Chrome و ویرایشگرهای سفارشی درج متن را محدود می‌کنند. کیفیت تشخیص و پشتیبانی سایت را در مرورگر و حساب خودتان آزمایش کنید.

## مجوزها و داده

- `activeTab` و `scripting`: اتصال به تب فعال و درج متن، فقط پس از اقدام کاربر.
- `storage`: تنظیمات، نشست و تاریخچهٔ اختیاری.
- `offscreen`: دسترسی لازم برای اجرای نشست گفتار در extension context.
- `commands`: میانبر شروع/توقف.
- `clipboardRead` و `clipboardWrite`: مجوزهای اختیاری که فقط برای قابلیت Clipboard درخواست می‌شوند.
- افزونه مجوز host برای هیچ دامنه‌ای تعریف نمی‌کند و درخواست مستقیم شبکه یا آپلود صوت از کد افزونه ندارد. سرویس تشخیص احتمالی Chrome/Google تحت کنترل افزونه نیست.

## بررسی و ساخت آرشیو

Node.js 18+ و Python 3 لازم است:

```bash
npm test
npm run check
npm run package
```

`npm run package` آزمون‌ها و بررسی فایل‌ها را اجرا می‌کند و آرشیو نصب‌پذیر `VocaType-Chrome-Extension.zip` را در ریشه می‌سازد.
