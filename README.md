# تجربه‌ی یک‌سکشنِ معرفی سامانه‌ی ساخت کلیشه

## اجرا

فایل `index.html` را مستقیماً در Chrome یا Edge باز کنید. تمام HTML، CSS و JavaScript در همین فایل قرار دارند؛ اجرا به Backend یا کتابخانه‌ی JavaScript نیاز ندارد. تصویر بهینه‌شده‌ی دستگاه در `assets/plate-maker-hero.webp` است. فونت وزیرمتن از Google Fonts دریافت می‌شود و در حالت آفلاین، فونت جایگزین سیستم استفاده خواهد شد.

## ساختار تجربه

کل معرفی در یک `<section>` پیوسته اجرا می‌شود. کادر محصول Sticky می‌ماند و با اسکرول، هشت مرحله‌ی معرفی، طراحی، کنترل، دقت، فرایند، ویژگی‌ها، مشخصات فنی و ارتباط به‌تدریج جای یکدیگر را می‌گیرند. نشانگر مرحله، حرکت شبه‌سه‌بعدی و افکت ورود مرحله‌ای متن به همین پیمایش متصل‌اند. تم فعلی گرافیتیِ تیره با نور استودیویی پشت محصول و اکسنت مسی است.

## پیش از انتشار نهایی

- تصویر پیوست‌شده در این پیام در فضای فایل‌های پروژه در دسترس نبود؛ بنابراین `assets/plate-maker-hero.webp` هنوز رندر استودیوییِ نسخه‌ی قبلی است. گوشه‌های عکس گرد شده و بک‌گراند آن در تم تیره با نور استودیویی blend می‌شود؛ اما فایل فعلی آلفای شفاف واقعی ندارد. برای حذف واقعی پس‌زمینه و استفاده از دستگاه درست، فایل اصلی باید در پوشه‌ی `assets` قرار بگیرد تا به‌صورت cutout پردازش شود.
- نام رسمی شرکت، اطلاعات تماس و دیتاشیت/اعداد فنی ارائه نشده بود. متن نام برند عمومی است و از درج مقادیر فنی حدسی پرهیز شده. پیوندهای ایمیل CTA نیز بدون گیرنده باز می‌شوند؛ پیش از انتشار، نشانی واقعی واحد فروش و اطلاعات تماس را وارد کنید.
