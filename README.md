# VocaType — تایپ صوتی چندزبانه برای Chrome

اکستنشن Manifest V3 برای دیکتهٔ فارسی، انگلیسی و عربی با پشتیبانی از واژه‌های فنی، فرمان صوتی، شناسهٔ زبان در حالت ابری و درج متن در محل مکان‌نما. هیچ کتابخانه یا کد اجرایی از CDN بارگیری نمی‌شود.

> **محدودیت مهم دقت:** برای تشخیص واقعی فارسی و جابه‌جایی فارسی/English در یک جمله، مسیر پیشنهادی Soniox real-time است و به اتصال اینترنت و سرویس/کلید خودتان نیاز دارد. تا زمانی که Token Broker پیکربندی نشده باشد، حالت Automatic به Web Speech API مرورگر برمی‌گردد؛ این fallback چندزبانهٔ هم‌زمان را تضمین نمی‌کند و ممکن است صدای شما را به سرویس تشخیص مرورگر بفرستد. خود Extension هیچ فایل صوتی خامی را ذخیره نمی‌کند.

## نصب در Chrome

1. فایل ZIP را Extract کنید.
2. در Chrome به `chrome://extensions` بروید و **Developer mode** را روشن کنید.
3. **Load unpacked** را بزنید و پوشهٔ `vocatyp-extension` را انتخاب کنید.
4. برای میانبر به `chrome://extensions/shortcuts` بروید. میانبر پیشنهادی `Ctrl+Shift+2` است. می‌توانید آن را مطابق محدودیت‌های Chrome تغییر دهید.
5. در یک صفحهٔ عادی، روی فیلد متنی کلیک کنید و از Popup دکمهٔ شروع را بزنید یا از میانبر استفاده کنید. صفحه‌های `chrome://`، Chrome Web Store و بعضی ویرایشگرهای Canvas/iframe محدودیت مرورگر دارند.

## راه‌اندازی موتور ابری Soniox (پیشنهادی برای فارسی + English)

کلید دائمی Soniox را **داخل اکستنشن وارد نکنید**. Broker نمونه، کلید ماندگار را فقط در متغیر محیطی سرور نگه می‌دارد و برای هر نشست یک کلید موقت، تک‌مصرف و محدود صادر می‌کند.

### اجرای محلی Broker

1. از پوشهٔ `broker` فایل `.env.example` را به `.env` کپی کنید.
2. `SONIOX_API_KEY` و یک `BROKER_ACCESS_TOKEN` تصادفی و قوی تنظیم کنید. API Key باید در Soniox اجازهٔ ساخت کلید موقت و استفاده از STT را داشته باشد.
3. شناسهٔ اکستنشن را از `chrome://extensions` بردارید و در `ALLOWED_ORIGINS` قرار دهید؛ برای نصب Unpacked ممکن است شناسه با محل نصب تغییر کند.
4. در `broker` اجرا کنید:

   ```bash
   node --env-file=.env server.mjs
   ```

5. در Options اکستنشن، نشانی Broker را وارد کنید؛ برای تست محلی `http://localhost:8787/v1/session-token` مناسب است. در همان صفحه **ذخیره و اجازهٔ اتصال** را بزنید و Access Token همان Broker را وارد کنید.
6. موتور را روی **Automatic** یا **Soniox real-time** قرار دهید.

برای استفادهٔ خارج از سیستم خود، Broker را پشت HTTPS منتشر کنید، محدودیت مصرف و احراز هویت کاربر اضافه کنید و Origin دقیق اکستنشن را در تنظیمات سرور قرار دهید. Broker داخل این مخزن یک نمونهٔ Self-hosted است، نه سرویس عمومی چندکاربره. کپی‌کردن یک `BROKER_ACCESS_TOKEN` مشترک بین کاربران توصیه نمی‌شود.

## امکانات

- وضعیت‌های آماده، شروع، گوش‌دادن، در حال پردازش، اتصال مجدد، خطا و رد شدن دسترسی میکروفون.
- میانبر سراسری Chrome از `chrome.commands`؛ قابل تغییر در تنظیمات میانبرهای خود Chrome.
- Soniox streaming با نتیجهٔ موقت/نهایی، tokenهای زبان‌دار، تشخیص پایان گفتار و reconnect محدود.
- fallback مبتنی بر Web Speech API با پیام آشکار دربارهٔ محدودیت Auto/Mixed Language.
- درج در `input`، `textarea` و `contenteditable`، تلاش برای حفظ Cursor/Selection و ارسال رویداد `input` برای سازگاری بهتر با React/Vue/Angular.
- فرمان‌های فارسی و انگلیسی؛ تشخیص فرمان فقط وقتی کل عبارت نهایی دقیقاً با عبارت فرمان برابر باشد.
- اصلاح محافظه‌کارانهٔ ی/ک، فاصله/نیم‌فاصله، ارقام، علائم، واژه‌های فنی و Dictionary سفارشی.
- Floating Indicator قابل کشیدن، کوچک‌کردن و مخفی‌کردن.
- History به‌صورت پیش‌فرض خاموش، محدود و قابل پاک‌کردن؛ Debug نیز پیش‌فرض خاموش است.
- Copy/Paste صوتی فقط بعد از اعطای مجوز اختیاری Clipboard در Options کار می‌کند.

## حریم خصوصی و مجوزها

- ضبط صدا فقط پس از شروع صریح کاربر فعال می‌شود؛ هنگام توقف، Media Trackها بسته می‌شوند.
- در حالت Soniox، جریان صوتی و واژه‌های فنی/سفارشی برای تبدیل گفتار به متن و context تشخیص به سرویس Soniox ارسال می‌شوند. سیاست نگهداری سرویس‌دهنده خارج از کنترل این اکستنشن است.
- در حالت Web Speech، پردازش محلی به‌طور قطعی تضمین نمی‌شود؛ این موضوع به نسخهٔ Chrome، زبان و مدل نصب‌شده بستگی دارد.
- صدای خام ذخیره نمی‌شود. History متن فقط با فعال‌کردن گزینهٔ آن در مرورگر ذخیره می‌شود؛ خاموش‌کردن History، موارد قبلی را هم پاک می‌کند.
- مجوزهای میزبان Broker به‌صورت اختیاری و پس از اقدام کاربر درخواست می‌شوند. میکروفون از API مرورگر درخواست می‌شود و در Manifest مجوز میکروفون جعلی تعریف نشده است.
- اطلاعات Broker در `chrome.storage.local` این پروفایل مرورگر نگهداری می‌شود؛ این محل رمزنگاری‌شده برای مقابله با بدافزار یا دسترسی محلی نیست. API Key دائمی STT فقط باید روی Broker بماند.

## فرمان‌های صوتی

`خط جدید`، `پاراگراف جدید`، `پاک کن`، `همه رو پاک کن`، `کپی`، `بچسبون`، `برگرد`، `دوباره انجام بده`، `نقطه`، `ویرگول`، `علامت سوال`، `علامت تعجب`، `دو نقطه` و `نقطه ویرگول`.

برای جلوگیری از اجرای ناخواسته، عبارت فرمان باید به‌تنهایی در یک بخش نهایی گفته شود؛ واژهٔ «کپی» داخل جملهٔ معمولی فرمان اجرا نمی‌کند. پاک‌کردن گفتار نیز فقط روی آخرین متن دیکته‌شده و در صورتی اعمال می‌شود که فیلد از آن زمان تغییر نکرده باشد.

