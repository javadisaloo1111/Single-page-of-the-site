CHROME WEB SPEECH

تشخیص گفتار داخلی Chrome

VocaType از Web Speech API مرورگر استفاده می‌کند و صدا را به سرویس STT جداگانه‌ای ارسال نمی‌کند.

ⓘ
محدودیت زبان و حریم خصوصی

Chrome ممکن است صدای گفتار را برای تشخیص به سرویس گفتار Google بفرستد؛ رفتار دقیق به نسخهٔ Chrome و زبان بستگی دارد و پردازش کاملاً محلی تضمین‌شده نیست. این API برای جابه‌جایی هم‌زمان فارسی، English و عربی تضمین تشخیص قابل‌اعتماد نمی‌دهد؛ زبان انتخابی را با زبان غالب گفتار هماهنگ کنید.

TEXT PROCESSING

پردازش متن

اصلاحات محافظه‌کارانه، بدون ترجمه یا آوانویسی واژه‌های انگلیسی.

تبدیل واژه‌های عددی فارسی در عبارت‌های شناخته‌شده انجام می‌شود؛ موارد مبهم برای جلوگیری از تغییر معنی دست‌نخورده می‌مانند.

VOCABULARY

واژگان فنی و شخصی

واژه‌های سفارشی فقط پس از تشخیص، روی دستگاه برای استانداردسازی شکل transcript به‌کار می‌روند؛ به سرویس گفتار فرستاده نمی‌شوند و دقت آکوستیکی تشخیص را افزایش نمی‌دهند.

واژگان سفارشی

مثال: reactjs → React.js. این تبدیل فقط روی عبارت کامل انجام می‌شود.

PRIVACY & PERMISSIONS

حریم خصوصی

رفتار واقعی ذخیره‌سازی و انتقال داده.

🎙
صوت خام

VocaType فایل صوتی را ضبط یا ذخیره نمی‌کند؛ Chrome برای تشخیص از میکروفون استفاده می‌کند و ممکن است صدا را به سرویس Google بفرستد.

☁
ارسال برای تشخیص

اکستنشن از API گفتار داخلی Chrome استفاده می‌کند. Chrome ممکن است صدا را برای تشخیص به سرویس Google بفرستد؛ محلی‌بودن پردازش تضمین نیست و به مرورگر و زبان وابسته است.

▤
متن و تاریخچه

آخرین متن فقط در نشست مرورگر نگهداری می‌شود؛ تاریخچه به‌صورت پیش‌فرض خاموش و در صورت فعال‌شدن محدود است.

⌁
واژگان و مجوزها

واژگان سفارشی و تنظیمات فقط در storage محلی Chrome هستند. این اکستنشن کلید API یا اتصال به سرویس STT شخص ثالث ندارد. مجوزهای Clipboard تنها در صورت درخواست شما فعال می‌شوند.
